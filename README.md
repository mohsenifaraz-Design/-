# نقشه راه محصولات — سنی پلاستیک

داشبورد فارسی (راست‌به‌چپ) برای تعریف، امکان‌سنجی، ارزش‌دهی، شناخت بازار و رقبا، نقشه راه و تصویب نهایی پروژه‌های هر گروه محصولی (وان و جکوزی، شیرآلات، مکانیزم و فلاشتانک، درب و کفی فرنگی، یونیورست و یونیکا).

کل برنامه یک فایل است: `index.html`. نیازی به سرور یا نصب ندارد.

## اجرا روی کامپیوتر

فایل `index.html` را با مرورگر باز کنید. بدون تنظیم Firebase، اطلاعات فقط در همان مرورگر ذخیره می‌شود.

## انتشار روی GitHub Pages

۱. در GitHub یک ریپازیتوری بسازید و فایل‌های همین پوشه (`index.html`، `README.md`، `.nojekyll`) را در آن آپلود کنید.
۲. در ریپازیتوری: **Settings → Pages**. زیر Source گزینه **Deploy from a branch** را بزنید، شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
۳. بعد از چند دقیقه سایت روی آدرس `https://<نام‌کاربری>.github.io/<نام‌ریپازیتوری>/` بالا می‌آید.

> توجه: آدرس GitHub Pages عمومی است و هرکس لینک را داشته باشد صفحه را می‌بیند. اطلاعات پروژه‌ها (هزینه، آکورد، امتیاز) فقط وقتی در سایت دیده می‌شود که کسی آن را وارد یا از Firebase بخواند؛ به بخش امنیت پایین‌تر نگاه کنید.

## ذخیره مشترک بین همه کاربران (Firebase)

بدون این بخش، هر نفر فقط داده‌های خودش را روی مرورگر خودش می‌بیند.

۱. در [console.firebase.google.com](https://console.firebase.google.com) یک پروژه بسازید.
۲. **Build → Firestore Database → Create database** را بزنید.
۳. در تب **Rules** این متن را جایگزین و Publish کنید:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /projects/{docId} {
      allow read, write: if true;
    }
  }
}
```

۴. در **Project settings → General → Your apps** یک Web app (`</>`) ثبت کنید و مقدار `firebaseConfig` را کپی کنید.
۵. در `index.html` بخش `const firebaseConfig = {...}` (نزدیک ابتدای تگ script) را با همان مقادیر عوض کنید و دوباره آپلود کنید.

## امنیت

قانون بالا به هرکس که آدرس سایت را بداند اجازه خواندن و نوشتن می‌دهد. برای ابزار داخلی کوچک ممکن است کافی باشد، ولی اطلاعات مالی (قیمت تمام‌شده، سرمایه، آکورد) در دسترس هر کسی قرار می‌گیرد که لینک را پیدا کند. اگر این برایتان قابل قبول نیست، پیش از استفاده واقعی ورود با ایمیل (Firebase Authentication) و قانون محدودکننده اضافه شود.
